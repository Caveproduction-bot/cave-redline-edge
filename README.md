# Cave Redline Edge

A red-lit sci-fi command deck for the **CORSAIR XENEON EDGE**: your current focus, tasks,
media, PC and audio controls and live system performance on one 2560×720 touch screen.
Made by [Tom's Cave](https://marketplace.elgato.com/@tomscave) for iCUE 5.47 or later on
Windows.

Get it from **Elgato Marketplace**, then install the free bridge below.

## Download the free bridge

**[CaveRedlineEdgeBridge-Setup.exe](https://github.com/Caveproduction-bot/cave-redline-edge/releases/latest)**
from the Releases page.

The bridge is a small Windows program that powers audio controls, media details, the RAM
and network readings, the notification count, the screen buttons and Lock / Shut Down /
Restart. It starts with Windows, talks only to your own PC, and sends nothing to the
internet. Tasks, the focus timer, the clock, colours and the CPU and GPU readings all
work without it.

Full setup steps: **[SETUP.md](SETUP.md)**

## Features

- **Current focus:** start any task and it becomes your focus, with a big timer, a
  segmented progress bar towards its goal, elapsed and remaining time, Pause, Break Time
  and End Task
- **Break reminders:** a quiet window that appears while you work, says how long you have
  been at it and offers to start a break, and another when the break is over. Neither
  makes a sound and both go away on their own. Break length and how often to be reminded
  are in Options, set to ten minutes every hour to begin with.
- **Task operations:** Up Next with due dates, durations and priorities, Add Task with
  suggestions from past tasks, a calendar filter, a switch that hides completed tasks
  from Up Next, Undo on delete, and task stats
- **Work sessions:** every session with the hours worked and how far it got, the one
  running now at the top, everything still to do under SCHEDULED with START, finished
  work under COMPLETED, CONTINUE to pick a session back up, a tick box to finish its
  task, and an editor for the title, description, target and hours
- **Media:** artwork, title, artist and app, a progress bar you can drag, transport and
  volume, and switching between media apps
- **PC & audio controls:** mute, mic, Switch Sound, Sound Source, Movie Mode, Lock, and
  Shut Down and Restart behind a deliberate 1.5-second hold
- **System performance:** live CPU, GPU, RAM and network graphs with a one-line status
  that warns when something runs high for a while, and says what to set up when a
  reading is missing
- **Top bar:** your current sound output, Show desktop, display-mode switching, Windows
  Task Manager, Options, and swiping between iCUE pages using your iCUE Screen Setup
  shortcuts
- **Colours:** an accent, two text colours and a background, all set in iCUE. The accent
  carries the shell's neon, buttons, progress bar and graphs; Text Color 1 the headings
  and readings, Text Color 2 the labels, captions, due dates and links. A background
  colour paints the whole dashboard, shell and all, in that colour.
