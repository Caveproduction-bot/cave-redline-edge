# Changelog

## 1.0.0 — first release

First release of Cave Redline Edge: a red-lit sci-fi command deck for the CORSAIR
XENEON EDGE.

- Current focus with a big timer, segmented goal bar, Pause, Break Time and End Task
- Break reminders: a silent window every so often while you work, and a second one when
  the break is over, with break length and how often to be reminded set in Options (on
  every hour, ten-minute breaks, to start with)
- Task operations: Up Next, Add Task, calendar filter, a switch that hides completed
  tasks from Up Next, and task stats
- Work sessions: every logged session with CONTINUE and how far it got, tasks not yet
  started under SCHEDULED with START, finished work under COMPLETED, a tick box that
  finishes a task, and an editor for the title, description, target and hours
- Media, PC & audio controls, Windows Task Manager from the top bar, and Lock, Shut
  Down and Restart (press and hold)
- System performance with CPU, GPU, RAM and network graphs and a one-line status
- Colours set in iCUE: an accent, two text colours and a background. The accent carries
  the neon, buttons, bar and graphs; Text Color 1 the headings and readings, Text Color 2
  the labels, captions, due dates and links; and a background colour paints the whole
  dashboard, shell and all, in that colour
